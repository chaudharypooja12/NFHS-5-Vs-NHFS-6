# Rankings

**Route** `/states`
**Requirements** FR-07, FR-08  
**Status** Implemented in the local build

Rankings are integrated into the All States table. Select NFHS-6, NFHS-5, or eligible change as the ranking basis. Reuse the State selection, indicator selector, sorting buttons, factsheet links, and XLS export. Ranks are among selected eligible States, preserve ties, and use the indicator's approved direction. Context-dependent measures have explicitly numerical high-to-low ranks.

The legacy `/rankings` URL forwards to All States. The standalone explorer mode and ranking chart branches were removed. The consolidated table provides the analytical result without a second visualization.
