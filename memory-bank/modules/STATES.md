# All States and State factsheets

**Route** `/states and /states/[slug]`  
**Requirements** FR-02, FR-03, FR-04, FR-05, FR-08, FR-09

**Status** Implemented in the local build

All States has a two-column selection and performance layout. A scrollable checkbox panel lists all 28 States and eight UTs, with Select All, Clear, and a selected counter. UTs are presentation-only entries with unavailable data and no factsheet route. The underlying survey catalog is unchanged.

The performance panel has one Select Indicators dropdown, High to Low and Low to High buttons using NFHS-6 values, and a table with State, NFHS-6, NFHS-5, and Actions columns. Missing values sort last in either direction. State rows open the existing factsheet routes. Download XLS exports the current indicator and sorted selections in Excel BIFF8 format with units and source references.

The page ends after the selection and comparison cards. The standalone Institutional births section, chart, CSV export, and expandable data table were removed on 17 November 2026. Institutional births remains available in the performance indicator dropdown.

Each factsheet shows the State name under the State factsheet label and includes an indicator dropdown, filters, charts, tables, and references. Keep Manipur accessible with NFHS-5 data and an NFHS-6 availability explanation.
